# ADR 003: Local understanding reports and portable context

Accepted 2026-09-23. Phases 3 and 4 extend the existing modular monolith.

`UnderstandingCommands` owns risk, drift, element inspection, and session snapshot commands. Migration 3 adds `reports`; sessions reuse `repo_snapshots`, drift dispositions reuse `suppressions`, and all modules share findings and artifacts. A finding references either a browser run or an inspection report. Artifact `runId` is the evidence owner's ID for either kind. Finished reports and session snapshots remain readable with the target app offline.

The risk map parses TS/JS with the pinned TypeScript 6.0.3 compiler API under the `typescript-parser` alias. The build continues using TypeScript 7.0.2; its root module does not provide the older compiler API. Imports/re-exports/require with literal relative paths yield static edges, including transitive reverse dependencies. Next app/pages conventions yield static route candidates. JSX/object literal router paths and test filename matches are heuristic. Unresolved aliases, nonliteral imports, and dynamic wiring are explicit gaps. Observed navigation is recorded separately from static reachability. References: [official compiler API guide](https://github.com/microsoft/TypeScript/wiki/Using-the-Compiler-API).

Drift rules supply selectors, a computed property, allowed `values` (literal CSS or `var(--custom-property)`), and a pixel tolerance. No automatically inferred baseline is treated as authoritative. Selector rules distinguish button variants. Repeated identical outliers on a route share one finding and list all selectors/bounds. Screenshots highlight outliers; intentional/suppressed fingerprints carry into subsequent scans. Analysis covers colors, padding/margins/gap, font size, and border radius.

Element inspection accepts a selected CSS locator. DOM/styles/route are observed facts. Optional `data-dcr-*` metadata identifies application-supplied component/file/line/route/handler/state labels. `sourceProps` is a small framework-neutral helper, disabled unless explicitly enabled. The service also requires project bridge opt-in and validates referenced files. Metadata is not compiler verification, React state ownership, or network causality. Uninstrumented elements retain useful facts with unknown mapping. Sources and private DOM regions are filtered before persistence.

Session snapshots preserve Git status/recent commits, the latest and failing run, open findings, exact authored notes/next step, an editable/discardable suggestion, and the selected task. Resume uses the existing action preview and command approval; branches are never switched automatically. Snapshot Git state is historical, distinct from the current project state.

AI handoff is provider-neutral Markdown generated only by a user-initiated command. It supports project/run/finding/scenario/report/task/session/flow scopes, includes source excerpts from permitted referenced files, and applies current redaction. It distinguishes current source/Git from historical execution evidence, records limits/omissions, and references binary artifacts rather than pretending they are embedded. UI offers preview, clipboard copy and Markdown download; CLI and VS Code share the same service contract. No provider integration, telemetry, or remote transmission is added.

Limits: bounded source scan (2000 files, 256 KB per file); relative imports only; no arbitrary TS path aliases or runtime causality; selected-page screenshot viewport is 1280×800; no automatic auth/login setup for inspection; at most five drift routes per invocation. Active browser inspections are in-process. Reports are retained until project deletion; run retention does not delete reports. The editor extension is optional and source-distributed plus locally packaged VSIX.
